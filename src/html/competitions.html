Technical requirements

Read this before you build.

The host has published the configuration the field will run. Robots that do not match it will not pass inspection.

01 / Referee system

Bring your own modules

  • Purdue is not providing referee system modules
  • A limited number of spares may be lent on site
  • Every borrowed module must be returned before teardown
  • Firmware versions must match the host's published list

02 / Server & video

Modified 2025 RMUL server

  • Video transmission uses the VTM02 transmitter
  • Operators receive on VTM12 receivers
  • Flash the host-supplied firmware from the rmtool2 folder
  • Verify your link before leaving Urbana

03 / Field & rules

2026 ARC ruleset, 2v2

  • The field is the 2v2 layout from the 2025 Midwest Championship
  • Matches mirror the 2026 ARC Championship ruleset
  • Drive teams should review the ruleset before Oct 30
  • Inspection runs in STEW 204 on both days
