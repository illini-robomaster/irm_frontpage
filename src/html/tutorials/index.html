Learn the code behind the robots.

Embedded systems, CAN communication, and motor control — the same stack that runs our competition robots. Each tutorial stands alone, but they build on each other, so we recommend going in order.

Tutorial list

Three tutorials.
From socket to motor.

01

C++ Introduction with Linux CAN

An introduction to C++ programming concepts through the lens of CAN (Controller Area Network) communication on Linux systems. Covers basic C++ syntax, object-oriented programming, and Linux socket programming for CAN communication.

Beginner 30 minutes Prerequisites: Basic programming knowledge
Start PDF
02

C++ Introduction with STM32 CAN Implementation

A comprehensive tutorial on CAN protocol implementation at the hardware level using STM32 microcontrollers. Covers CAN frame structure, hardware abstraction layers, and real-time embedded programming concepts.

Intermediate 1 hour Prerequisites: C++ basics, embedded systems fundamentals
Start PDF
03

Introduction to Motor3508 Code Analysis

Detailed analysis of motor control code for the DJI M3508 motor. Covers class inheritance, virtual functions, interrupt handling, bit manipulation, and motor control algorithms including PID control.

Intermediate 1 hour Prerequisites: C++ OOP, basic motor communication

Getting started

Before you begin.

01 / Prerequisites

What you should know

  • Basic programming knowledge (preferably C++)
  • Familiarity with command-line interfaces
  • Basic electronics (for embedded tutorials)
  • A Linux development environment (for CAN tutorials)
  • STM32 development setup (for hardware tutorials)

02 / Environment

Recommended setup

  • Linux: Linux or WSL
  • IDE: VS Code or any IDE with C++ extensions
  • Compiler: The ARM GCC toolchain (see GitHub)
  • STM32: STM32CubeIDE and development boards
  • Version control: Git

03 / Resources

Further reading

  • iRM Embedded repository — source and examples
  • STM32 documentation — hardware reference
  • CAN in Automation — protocol specs
  • GitHub organization — all team repositories
  • The C++ Programming Language, Stroustrup
  • Design Patterns, Gang of Four
  • Embedded Systems Programming, Michael Barr
